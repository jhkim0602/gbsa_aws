기본 초대 메일 — 기업이 아무것도 수정하지 않아도 이렇게 나갑니다

현재 실제로 발송되는 메일은 영어 두 줄이 전부입니다. 아래가 제안하는 기본값입니다. 회사명·지원자명·포지션·마감일시는 이미 DB에 있는 값을 그대로 채웁니다.

데스크톱 · 600px Gmail / Outlook / 네이버메일 공통

자동으로 채워지는 값

  • {{회사명}} — company.name
  • {{지원자명}} — invitation.applicant_display_name
  • {{포지션명}} — position.title
  • {{마감일시}} — invitation.expires_at
  • {{면접링크}} — 1회용 토큰 URL

이메일 HTML 제약을 지킨 마크업

  • table 레이아웃 + 인라인 CSS만 사용
  • flex / grid / <style> 미사용 (Outlook 무시)
  • 버튼은 이미지가 아니라 텍스트 — 이미지 차단 환경에서도 보임
  • 다크모드에서 글자 사라지지 않도록 배경·전경 동시 지정

이미 준비된 자리

  • company.brand_config (JSON) 컬럼이 이미 존재하고 스펙에도 "Logo/color/display metadata only"로 적혀 있습니다. 다만 읽는 코드가 한 줄도 없습니다.
  • 로컬 mailpit이 붙어 있어 실제 발송 렌더링을 바로 검증할 수 있습니다

로고 업로드는 신설이 필요합니다

  • 메일 속 이미지는 공개 HTTPS 절대 URL이어야 합니다
  • 현재 업로드 경로는 전부 비공개 presigned 방식 — 메일에 못 씁니다
  • 공개 읽기 전용 접두사 + CDN 경유가 추가로 필요합니다
